# Smart Calculator (CLI)

A modular command-line calculator built using Python.

## Features
- Addition, Subtraction, Multiplication, Division
- Input validation with exception handling
- Modular design using separate operations module
- Persistent calculation history stored in a file

## Tech Stack
- Python
- Git
- GitHub

## Project Structure
Smart-Calculator/
│
├── main.py
├── operations.py
├── history.txt


## How to Run
```bash
python main.py
```
